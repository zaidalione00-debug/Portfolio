# Software Engineering Portfolio

A responsive, editorial portfolio built with semantic HTML, CSS, and vanilla JavaScript. The warm paper palette, restrained red accent, typography-led layout, and project index are designed to read more like a student's working portfolio than a template. Personal details, education information, projects, credentials, and profile links remain marked as placeholders rather than making unsupported claims.

## Project files

- `index.html` — all portfolio sections and editable content
- `style.css` — typography, editorial layouts, responsive rules, and reduced-motion support
- `script.js` — accessible mobile navigation and current-year footer
- `assets/resume/` — place your PDF resume here as `your-resume.pdf`

## Run locally

1. Replace the bracketed placeholders and `Your Name` in `index.html` with accurate information.
2. Update the example address `your.email@example.com` in the contact link to your email.
3. Add your PDF as `assets/resume/your-resume.pdf`, or change the resume link to match your filename.
4. Open `index.html` in a modern browser. No build step or package installation is required.

For a local development server, run `npx serve .` from this folder if Node.js is already installed, then open the local URL printed by the command.

## Before sharing

- Replace all `[placeholder]` content and remove any unused entries.
- Set a truthful status for every project: planned, in progress, or completed.
- Replace each project screenshot prompt in `index.html` with an authentic screenshot of your own work and a useful alt description.
- Add real profile URLs only after verifying them.
- Include only completed certifications, awards, and experience; label active training clearly.
- The resume download will work after the PDF is added at the expected path.

Google Fonts are optional; the page falls back to system sans-serif, serif, and monospace fonts if the font service is unavailable. This project is local-only and does not submit or store contact messages; the contact action opens the visitor's default email application.
