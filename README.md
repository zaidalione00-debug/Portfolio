# Software Engineering Portfolio

A responsive portfolio for Zaid Ali, a iSoftware Engineering student at the University of Sindh. The site uses semantic HTML, CSS, and vanilla JavaScript with a charcoal palette and restrained editorial styling.

## Project files

- `index.html` — portfolio content and assignment sections
- `style.css` — typography, layout, and responsive styles
- `script.js` — mobile navigation and current-year footer
- `assets/images/profile.jpg` — profile photograph
- `assets/certificates/ai-skills-passport.pdf` — AI Skills Passport certificate

## Assignment sections.

The page contains 13 main content sections plus navigation and footer, covering all 14 required items. It includes three ongoing projects, a concise Fancy Wear case study, academic experience, the verified AI Skills Passport certificate, GitHub and LinkedIn profiles, and email contact.

No CV PDF is present in the project, so the CV section has no download link. Project entries use only the technologies and descriptions currently listed in the page; no repository links are provided.

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required.

The site uses system fonts and makes no external font requests. Contact links open the visitor's default email application; the site does not submit or store messages.
